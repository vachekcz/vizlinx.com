## Build a assety

- **Dev:** `npm run dev` = `vite --host 127.0.0.1` → http://127.0.0.1:5173 s HMR. Servíruje **jen frontend**: `/api/*` neexistuje, takže `/scan` nefunguje ([06](./06-known-issues.md)). Celou aplikaci lokálně dává `npm run dev:full` / `npm run dev:api` na 8797 ([10](./10-local-setup.md)).
- **Produkce:** `npm run build` = `tsc -b && vite build && npm run build:extension`. Nejdřív typová kontrola všech čtyř projektů (app, node/testy, worker, extension), pak Vite bundle do `dist/` (`index.html`, hashované soubory v `dist/assets/`), nakonec build rozšíření (níže). `dist/` servíruje Workers Static Assets se SPA fallbackem ([04](./04-deployment.md)); do gitu nepatří.
- **Preview:** `npm run preview` = `vite preview --host 127.0.0.1` → 4173 nad `dist/`, opět bez API. Používá ho Playwright jako `webServer` ([05](./05-testing.md)).
- **`public/`** se kopíruje 1:1: `_headers` (CSP, `X-Robots-Tag: noindex, nofollow`, cache pro `/assets/*`), `favicon.svg` a statické archivy návrhů `/palettes/` (5 barevných variant) a `/connections/` (8 stylů spojnic) — samostatné HTML + PNG mimo React.
- **CSP** (`public/_headers`) povoluje jen vlastní origin (`script-src 'self'`, `connect-src 'self'`, `font-src 'self'`) a inline styly. Nový externí skript, font nebo API host tedy znamená úpravu `_headers`.

## Struktura

```text
src/
├── main.tsx              # entry: nastaví data-theme, vybere obrazovku podle pathname
├── App.tsx               # shell workspace: hlavička, seznam webů, mapa, inspektor, tabulka/CSV; props dataset + live
├── Graph.tsx             # SVG mapa: clustery, stránky, spojnice, drag/zoom, klávesnice, responsivita
├── Inspector.tsx         # pravý panel s detailem webu / stránky / vazby
├── ConnectionStroke.tsx  # styly spojnic (Silk výchozí) + FineConnectionStroke.tsx, connectionStyles.ts
├── ConnectionLab.tsx     # /connections/lab — izolovaná studie spojnic (+ connection-lab.css)
├── data.ts               # typy grafu a ukázková data dema (links, strengthLinks)
├── graph-data.tsx        # GraphDataProvider, demoDataset, useGraphData
├── scan-dataset.ts       # scanToDataset: ScanSnapshot → GraphDataset (stabilní pozice z hashe originu)
├── ScanWorkspace.tsx     # /scan: relace, založení mapy, ovládání, polling, historie běhů, přidání webu
├── ScanLogPanel.tsx      # panel „Průběh skenu“ a indikátor aktivity; čte /log
├── themes.ts             # ThemeId, initialTheme, useTheme
└── styles.css, themes.css, scan-workspace.css
```

**Kde začít číst:** `src/main.tsx` → podle cesty `App` (demo), `ScanWorkspace` (skener) nebo `ConnectionLab`. `ScanWorkspace` obaluje tentýž `App` s `dataset` ze `scanToDataset` a s `live` ovládáním, takže demo a živá mapa sdílejí jednu komponentu.

Typy API bere frontend přímo ze `shared/scan.ts` (`src/ScanWorkspace.tsx:22`) — kontrakt se neduplikuje.

## Routing a stav

- **Routing:** bez knihovny. `src/main.tsx:14` porovnává `window.location.pathname` bez koncového lomítka: `/connections/lab` → `ConnectionLab`, `/scan` → `ScanWorkspace`, cokoli jiného → demo `App`. Server vrací `index.html` pro každou neznámou cestu (SPA fallback), proto fungují přímé odkazy.
- **UX studie:** `/ux` je galerie tří interaktivních návrhů, `/ux/1` pracovní plocha, `/ux/2` mapa s plovoucím ovládáním a `/ux/3` analytický přehled. `src/ux/UxStudies.tsx` se načítá přes `React.lazy` jen pod `/ux`; styly jsou omezené třídou `.ux`. Současné `/` a `/scan` zůstávají stejné. Návrhy sdílejí `Graph`, `GraphDataProvider`, původní data a tokeny Signal/Midnight. Náhledy galerie jsou v `public/ux-previews/`.
- **Rozsah studií:** mapa a detail, formulář nové mapy, místní přepínání pauzy/intervalů, log, tabulka s hledáním a filtrem `nofollow`, CSV a ukázka aktuálního/archivního průchodu. Vše běží bez API; zadané adresy pouze přejmenují ukázkové weby. Reload obnoví výchozí data, jen volba tématu používá původní úložiště prohlížeče. Historie ani skenování nejsou napojené na Worker. CSV je označené `data_source=ux_mockup`. Studie jsou podklad pro výběr směru, nikoli schválený redesign nebo nový produkční kontrakt.
- **Panel webů ve variantě 2:** výchozí ukázka má dva skenované weby, hledání podle domény/názvu a kapacitu „2 ze 3 webů“. Řádky oddělují načtené stránky a známé URL popiskem „Celkem: 3 stránky · 6 URL“ se skloňováním podle počtu; v ukázkových datech jsou načtené stránky odvozené ze zdrojů vazeb a dokončených místních ručních skenů. Stejný součet používá spodní lišta i souhrn průběhu. Pauza počty neskrývá. Výběr webu aktivuje celý řádek včetně ikony a počtů; řádek reaguje na hover a klávesnicový fokus. Ovládání skenu a odkaz ven mají vlastní klikací plochy; odkaz při hoveru/fokusu zvýrazní samostatný rámeček. Ikona webu i tlačítko skenu zůstávají ukotvené nahoře při zobrazení stavového řádku. Vedle domény je samostatný odkaz do nové karty přes sdílený `ExternalLink`; nevybírá web v mapě. Akce v řádku přepíná mezi „Skenovat znovu“ (ikona obnovení), pauzou a pokračováním podle stavu konkrétního webu. Opakovaný sken spustí jen vybraný web, globální ovládání pracuje se všemi aktivními weby. Dokončení ukázky v logu vrátí akce na obnovení; archiv změny nepovoluje. „Přidat web“ doplní třetí web do stejné místní mapy se zachováním výsledků a nastavení; validuje adresu a duplicitu, v archivu a při plné kapacitě je zakázané. „Nová mapa“ zůstává samostatnou akcí v záhlaví.
- **Nová mapa ve variantě 2:** jediná karta uprostřed s nadpisem „Nová mapa“, krátkou instrukcí a jedním prázdným polem. Předchozí weby se nepředvyplňují. Další pole se přidávají nejvýše do tří; počítadlo uvádí neprázdné adresy, nikoli počet polí. Neplatná adresa a duplicita po normalizaci mají vlastní chybu pod příslušným polem, první chyba získá fokus. Po odeslání se chyby přepočítávají při úpravě i odebrání pole. Přidání a odebrání přesouvá fokus do navazujícího pole. Stačí libovolné jedno vyplněné pole; prázdná se ignorují, všechny neprázdné adresy musí projít validací. Zpět zachová současnou mapu, úspěšné vytvoření použije dosavadní ukázkový tok bez API. Každé nové otevření formuláře začíná prázdné. Velký úvod a tři číslované kroky jsou odstraněné, informace o účtu a pokračování po zavření karty jsou v krátké poznámce. Limit 1 000 stránek ze sdíleného `SCAN_LIMITS`, omezení veřejného HTML a upozornění na ukázková data zůstávají.
- **Nastavení skenu ve variantě 2:** rozbalovací sekce pod seznamem webů uvádí „Prodleva mezi načítáním stránek“ a vysvětluje vztah mezi prodlevou, rychlostí skenu a zátěží webu. Hodnoty 1/3/5/10/30/60 sekund zůstávají samostatné pro každý web; jednotky se vypisují slovy. Záhlaví i ve sbaleném stavu ukazuje společnou hodnotu (např. „3 s“), nebo „Různé“, pokud se prodlevy liší. Souhrn vychází ze všech skenovaných webů, nezávisí na hledání v seznamu a přepočítá se i po přidání dalšího webu. V archivu je změna intervalů nadále zakázaná. Informace o limitu 1 000 stránek a veřejném HTML bez JavaScriptu zůstávají viditelné v rozbalené sekci; jde o místní stav mockupu, bez napojení na skenovací API.
- **Detail ve variantě 2:** na mapě se otevírá těsně napravo od seznamu webů, s horní hranou zarovnanou k panelu. Šipka ukazuje na viditelný vybraný řádek a sleduje změny jeho výšky i posun seznamu. Navazující detaily webu, stránky a propojení zůstávají na stejném místě. Propojené weby jsou seskupené podle protějšího webu: doména je jeden neklikací nadpis se samostatnou ikonou odkazu do nové karty. Pod ním jsou kompaktní klikací boxy „5 odkazů ven“ / „3 odkazy sem“ se směrovou šipkou; úplný zdroj a cíl zachovává přístupný popisek. Zobrazují se pouze směry s odkazy, odchozí je první. Každý box samostatně spouští hover/fokus v mapě a otevírá odpovídající směrový detail; detail propojení uvádí zdroj → cíl a počet odkazů. Obě domény mají ikonu pro otevření webu; v detailu konkrétního odkazu je doména menší a tlumená, zatímco cesta stránky je výraznější. Vedle cesty jsou samostatné ikony pro otevření celé URL v nové kartě a její kopírování. Kopírování potvrdí fajfka a přístupné oznámení až po úspěšném zápisu do schránky; selhání zobrazí text s možností zopakovat akci. Ikony mají vlastní rámeček při hoveru/fokusu a nemění výběr ani návratovou cestu. Po dobu otevřeného detailu propojení se v mapě opakuje jemný puls a světelný úsek ve směru vybrané šipky, i bez query pro porovnání hoveru. Hover/fokus jiného prvku nebo přehraná ukázka mají dočasnou přednost; po jejich skončení se efekt detailu obnoví. Odchod do jiného detailu, zpět na web, zavření panelu nebo přepnutí z mapy opakování vypne. Při rozbalených webech se zvýrazní odpovídající jednotlivé spojnice; omezený pohyb ponechá pouze statické zvýraznění. Navigace uvnitř detailu uchovává cestu web → propojení → odkaz: tlačítko zpět vrátí předchozí obsah, scroll i fokus na původní řádek. Původní web zůstává zvýrazněný v seznamu a spojený šipkou s panelem. Přímý výběr v mapě/seznamu začíná novou cestu, křížek ji zavře. „Ukázat tento odkaz v mapě“ rozbalí oba koncové weby, zachová ostatní rozbalené weby a ponechá vybraný konkrétní odkaz i jeho otevřený detail a návratovou cestu; ostatní spojnice se utlumí. Na mobilu se detail otevírá ve spodním panelu se třemi výškami; otevření seznamu webů detail zavře. Obsah detailů zůstává zachovaný a delší obsah má vlastní scroll.
- **Stránky webu ve variantě 2:** tlačítko „Zobrazit stránky v mapě“ / „Sbalit stránky v mapě“ pouze mění rozbalení bubliny, nespouští sken. Pod propojenými weby je kompaktní `StudyPages` se všemi známými ukázkovými stránkami daného webu, nikoli jen konci zobrazených vazeb. Hledá v celé URL, cestě i názvu, ukazuje počet výsledků a má vlastní posouvání. Řádek otevírá detail stránky a zachovává návratovou cestu, filtr, posunutí seznamu i fokus; ikona nové karty a ▶ Proskenovat jsou samostatné. Stavy Nenačtená / Čeká / Načítá se / Načtená / Chyba doplňuje Vynechaná pro známý zákaz či nepodporovaný obsah, důvod se neztrácí. Používá `Page` a `PageScanButton` společné se skutečným skenerem. `useStudyPageScans` pouze místně simuluje čekání, načítání a úspěch bez požadavků API a bez přidávání skutečných odkazů. Pauza zastaví postup, archiv zakazuje nové akce a neukazuje čekající práci minulého běhu. Hotové místní výsledky jsou oddělené podle mapy a průchodu, přidání třetího webu je zachová, nová mapa začíná bez nich i při stejných adresách. Reload ukázku obnoví. Stejný stav a akce jsou i v detailu stránky. Desktopové záhlaví se zavřením zůstává při čtení seznamu dostupné; mobilní akce mají 44px dotykovou plochu.
- **Tabulka odkazů ve variantě 2:** panel má jediný nadpis „Odkazy“ s počtem výsledků podle aktuálních filtrů. Zdroj i cíl zvýrazňují cestu stránky, doména je menší a tlumená. Vedle cest jsou samostatné ikony pro otevření celé URL v nové kartě s vlastním hover/fokus rámečkem. Kliknutí na kteroukoli běžnou část řádku otevře detail; externí odkazy jej neotevírají a klávesnice používá tlačítko detailu s ikonou `›`. Všechny sloupce včetně textu odkazu a `nofollow` zůstávají dostupné i na mobilu posunutím tabulky vodorovně. Hledání, filtr `nofollow` a filtrovaný CSV export zůstávají zachované. Seznam má vlastní scroll, takže detail je viditelný i po výběru dolního řádku a jeho zavření zachová místo v seznamu.
- **Porovnání hover efektů:** `/ux/2?hover=pulse`, `?hover=quiet` a `?hover=focus` nabízejí tři interaktivní varianty (opakovaný puls koulí a průběh po spojnici, statická záře, zvýraznění s utlumením okolí). Přepínač mění query bez resetu mapy. Bez parametru je porovnání vypnuté; otevře ho „Varianty hoveru“ v liště studie. Hover/fokus řádku ukazuje konkrétní web nebo směrové propojení bez změny výběru, historie detailu, rozložení a přiblížení; odkaz ven a akce skenu jsou samostatné. Při zvýraznění propojení mají obrysy, záře a puls obou koncových webů čtvrtinovou opacity oproti zvýraznění samotného webu, aby vynikla spojnice. Platí pro hover, přehrání i otevřený detail; intenzita spojnice a samostatného webu zůstává stejná. Animované efekty se opakují po celou dobu hoveru/fokusu: puls koulí u webů i směrových propojení a průběh po spojnici u boxů v „Propojených webech“ i stránek v rozbalené kouli. Po opuštění náhledu se obnoví původní stav. Rozbalené weby zvýrazňují odpovídající jednotlivé spojnice. Tlačítka ukázky přehrají efekt na 3 sekundy; na mobilu dočasně odkryjí mapu a pak obnoví panel. Omezený pohyb vypne puls/průběh a ponechá statické zvýraznění. `Graph` přijímá volitelný `highlight` oddělený od `selection`; používají ho pouze tyto mockupy, vzhled efektů je v `src/ux/hover-studies.css`.
- **Hover stránek v rozbalené kouli varianty 2:** najetí myší nebo klávesnicový fokus na stránku zvýrazní pouze její příchozí a odchozí odkazy, s opakovaným průběhem ve skutečném směru spojnice po celou dobu hoveru nebo fokusu. Ostatní čáry se dočasně ztlumí. Náhled nemění výběr, detail, návratovou cestu, rozbalení ani polohu a přiblížení mapy. Po odjetí či ztrátě fokusu se obnoví předchozí stav včetně zvýraznění otevřeného propojení. Kliknutí a Enter nadále vybírají stránku; samostatná ikona odkazu ven náhled nespouští, dotykový pohyb také ne. Koncové weby používají stejnou čtvrtinovou intenzitu jako náhled propojení, reduced motion vypíná pohyb. Funguje i bez query pro hover (výchozí Puls); zapnuté porovnání používá zvolenou variantu. `Graph` přijímá volitelné `previewEvents` pro SVG stránky a `highlight` nově podporuje cíl `page`; zapojené jsou jen ve variantě 2.
- **Spodní lišta a historie varianty 2:** tlačítko „Průběh skenu“ má při aktivním skenu otáčející se ikonu (respektuje omezení pohybu), počet chyb a souhrn načtených a neúspěšných/vynechaných stránek pod boxem, vycentrovaný pod pravým ovládáním. Záložka Historie zobrazuje badge s počtem dostupných běhů, i na mobilu. Počty problémů i filtr logu čtou stejný místní seznam ukázkových HTTP/síťových chyb a vynechání kvůli robots.txt; nejde o výsledky API. Historie je kompaktní panel široký nejvýše 540 px, výchozí ukázka obsahuje aktuální běh #6 a pět archivů. Výběr uchovává konkrétní číslo průchodu, podle něj odvodí ukázkovou podmnožinu vazeb a zakáže ovládání archivu. Vysvětlení vazby přístupu na prohlížeč je dostupné po rozbalení poznámky pod mapou; výsledky produkčního skenu jsou na serveru, retence 30 dní a smazání dat prohlížeče může zrušit přístup.
- **Průběh skenu ve variantě 2:** samostatný `src/ux/StudyLogDialog.tsx` zachovává filtr webu, „Jen chyby“ a souhrn všech chyb a neúspěšných/vynechaných stránek. Záhlaví označuje číslo aktuálního nebo archivního běhu. Kompaktní řádky oddělují čas, ikonu a název události od celých URL; HTTP stav a počet nalezených odkazů jsou samostatná metadata. Ukázkové přesměrování uvádí zdroj i cíl včetně protokolu a vlastní ikony do nové karty. Opakované štítky „OK“ jsou odstraněné. Záhlaví, filtry a patička zůstávají pevné, posouvá se jen seznam událostí od nejnovějších. Při čtení starších řádků kompenzuje vložení nahoře jejich výšku a nabízí „K nejnovějším“; změna filtru obnoví sledování začátku seznamu. V otevřeném aktivním logu každé 3 sekundy přibude místní ukázka načítání stránky aktivního nepozastaveného webu. Pauza, archiv a dokončení přidávání zastaví, zavření a znovuotevření zachová události stejného běhu. Přepnutí běhu nebo složení webů vytvoří novou ukázku; nejde o perzistentní historii ani skutečný postup crawleru. Počty načtených stránek a výsledků zůstávají odvozené z ukázkové mapy. Tlačítko dokončení ukázkového skenu zůstává dostupné mimo dokončený běh a archiv. Escape či zavření obnoví fokus spouštěcího tlačítka. Původní log variant 1 a 3 zůstává samostatný.
- **Ovládání mapy ve variantě 2:** `StudyMapControls` soustředí zoom, procenta, „Zobrazit celou mapu“ a „Obnovit rozložení“ do jedné lišty. `Graph` poskytuje volitelný `renderControls`; bez něj používá původní ovládání. Zobrazení celé mapy změří lokální SVG obálku aktuální kresby včetně rozbalených stránek a přizpůsobí kameru volnému prostoru kolem skutečných panelů. Ruční polohy, rozbalení, výběr i cesta detailu zůstávají zachované. Samostatné obnovení vrátí výchozí polohy, sbalí stránky, zavře detail a znovu přizpůsobí pohled dostupnému prostoru; procento přiblížení tedy závisí na velikosti plochy. Tlačítka a kolečko používají rozsah 10–280 %, zobrazení celé mapy může při nedostatku místa oddálit i pod tuto mez; následné přiblížení navazuje plynule na vypočtenou hodnotu. Horní reset je odstraněný, reset u nápovědy se v této variantě nevykresluje. Kolečko, tažení a tlačítka přiblížení dál fungují. Hover a klávesnicový fokus otevírají jednu společně řízenou nápovědu s názvem a dopadem akce; Escape ji zavře i při hoveru mimo fokusované tlačítko. Na mobilu zůstává detail nad ovládáním. „Zobrazit celou mapu“ nejprve sbalí detail na proužek se zachovaným výběrem a obsahem, poté změří jeho konečný obrys a vycentruje mapu. Opětovné otevření vrátí obsah, scroll a navigaci bez změny kamery. Nápověda tuto akci popisuje; Escape má nejprve přednost pro zavření nápovědy. Barvy čtou stávající tokeny Signal/Midnight. Produkční `/scan`, demo `/` a studie 1 a 3 si ponechávají původní ovládání a reset.

### Částečně prozkoumané externí weby

`scanToDataset` přenáší `PageResult.crawlMode` na stránku grafu a externím webům dopočítává `Site.preview`. `Site.scanned` nadále označuje zařazení originu do běžného skenu, nikoli úspěšné prozkoumání celého webu. Automatická kontrola cílových URL tak nezabírá místo v limitu tří vybraných webů.

- **Rozsah kontroly:** `knownTargets` jsou unikátní cílové URL přímých odkazů z vybraných webů na daný externí web. `checkedTargets` počítá jen úspěšně načtené cíle; při přesměrování sleduje uložený řetězec stejného originu i povolených HTTP/HTTPS a www variant až k výsledku. Jednotlivé kroky přesměrování nezvětšují počet přímých cílů. Dosud nezpracovaný cíl přesměrování není chyba; cyklus se nerozvíjí donekonečna. `failedTargets` odlišuje cíle s neúspěšným výsledkem. `attemptedPages` a `inspectedPages` počítají skutečné preview a ruční výsledky a jejich úspěšnou podmnožinu.
- **Stavy a tvrzení:** úspěšná kontrola alespoň jedné stránky znamená „Částečně prozkoumáno“, pouze neúspěšně ověřené cíle „Nepodařilo se ověřit“, rozpracované přesměrování „Zatím neověřeno“, web bez výsledku „Neprozkoumáno“. Detail uvádí „Zkontrolováno X z Y známých cílových URL z vybraných webů“. Ani X = Y neznamená celý web. Nenalezený zpětný odkaz se vztahuje jen ke zkontrolovaným stránkám; chyby mají vlastní sdělení a detail výsledku.
- **Zpětné vazby:** `backlinkCount` počítá unikátní dvojice zdrojové a cílové stránky směřující zpět na některý z vybraných webů, který na tento externí web odkazoval. Cílem může být libovolná stránka původního originu. Stejné směrové hrany, metadata a detail URL používá mapa i pro ostatní uložené odkazy z kontrolovaných stránek. Weby objevené teprve z jejich odkazů mohou zůstat jen známými cíli bez kontroly.
- **Viditelnost:** web s preview nebo ručním výsledkem zůstává viditelný i při vypnutí dalších neprozkoumaných externích webů. Označení částečné kontroly je v seznamu webů, bublině i inspektoru; aktivita a log rozlišují `crawlMode: 'preview'` a ruční sken (`'manual'`) od běžného skenu.
- **„Prozkoumat web“:** inspektor předá origin do `ScanWorkspace`, který zavolá `/sites` a poté `/start`. Zůstane stejná mapa, dosavadní výsledky i ruční poloha bubliny. Origin začne zabírat jedno ze tří míst pro běžný sken; jeho dřívější výsledky dál nesou původní `crawlMode` a započítávají se do limitu 1 000 stránek na web. Při plném scope je akce zakázaná s vysvětlením. Archivní průchod je pouze ke čtení. Pokud přidání uspěje, ale start selže, přidaný web a výsledky zůstanou zachované a UI nabídne pokračování.

### Ruční sken nalezené stránky

- **▶ Proskenovat** je u známé URL bez výsledku v rozbaleném grafu, detailu stránky, detailu cíle odkazu a seznamu stránek webu. Volá `POST /scans/:id/pages` s `{ url, runId }`; nevybírá další web do běžného skenu, takže funguje i při obsazených třech místech. Načte konkrétní stránku a přidá její odkazy do stejného grafu; další HTML odkazy ani cíl přesměrování automaticky nespouští. Potvrzené aliasy zůstávají pod společným vlastníkem webu a sdílejí jeho limit i pauzu.
- `ScanSnapshot.pendingPages` drží čekající ručně vybrané URL. Akce je během mutace a čekání zakázaná; aktivita `fetching_page` u stejné URL zobrazí probíhající sken. Výsledek ukáže stav nebo chybu a další play už nenabízí. Archivní průchod je pouze ke čtení. U pozastavené mapy nebo webu je nutné nejprve pokračovat ve skenování; play je zakázané a důvod je v titulku tlačítka a detailu stránky. Stejně je zakázané při dosažení časového nebo úložného limitu průchodu. Selhání požadavku zobrazí společný chybový panel; polling ani mutace nemažou existující graf.
- Graf zobrazuje nejvýše 60 URL na web. Inspektor obsahuje prohledávatelný seznam všech známých stránek po 20 položkách, včetně interních objevených URL a cílů přesměrování. Seznam webů a přepínač webu v inspektoru (dostupný i na mobilu) zahrnují i domény mimo limit deseti neprozkoumaných externích bublin v grafu. Ručně prozkoumaný externí web zůstává viditelný podobně jako web s automatickou kontrolou cíle; nejde o prozkoumání celého webu.

Přesnou identitu URL určuje sdílený URL kontrakt. Serverem potvrzené aliasy z `PageResult.siteOrigin` a přesměrování `site_variant` patří v mapě pod původního logického vlastníka webu; pouhá podobnost domén nestačí. Jeho `Site.id`, poloha, barva, pauza, interval a počty stránek zůstávají společné, zatímco `Page.id` a `Page.url` uchovávají skutečnou HTTP/HTTPS adresu včetně hostname. Samostatně zadaný `ScanSite` se neslučuje s jiným vybraným webem. Limity automatických kontrol, síťová pravidla a chování po povýšení drží [backendová reference](./01-backend.md#automatická-kontrola-externích-cílových-stránek).

Povolené přesměrování, jehož cílový řetězec je úspěšný nebo dosud čeká na výsledek, nezvyšuje počet neúspěšných/vynechaných stránek ani seznam neúplných výsledků. Log nadále ukazuje původní URL, cílovou URL a HTTP stav každého uloženého kroku, včetně `robots.txt`. Rozlišuje nepovolený externí cíl, neplatnou adresu, zacyklení a limit přesměrování. Stejné zobrazení platí pro archivní běhy; staré události `external` si zachovávají význam „nenásledováno“.

### Rozlišení chyb robots.txt

Log, podrobnosti a inspektor odlišují `robots_denied` (zákaz načteným pravidlem) od `robots_unavailable` (načtení pravidel selhalo, skenování zastaveno). `robots_unavailable` se počítá do chybového odznaku. Starší archivní záznamy se nepřeklasifikují.

## Styling a theming

- **Systém:** čisté CSS; tokeny jako custom properties na `:root` (`src/styles.css:4`), přepis podle `[data-theme]` v `src/themes.css`, styly skeneru v `src/scan-workspace.css`. Fonty: DM Sans Variable pro text, Manrope Variable pro titulky.
- **Témata:** `signal` (světlé) a `midnight` (tmavé), `ThemeId` v `src/themes.ts`. Pořadí: `?theme=` → `localStorage['vizlinx-theme']` → `prefers-color-scheme` (`initialTheme`, `src/themes.ts:26`). `main.tsx` nastaví `data-theme` na `<html>` **před** prvním renderem, aby stránka nebliknula. Přepínač (`useTheme`) uloží volbu do localStorage a odstraní `theme` z URL (`src/themes.ts:47`); bez uložené volby vzhled sleduje systém živě.
- **Směr spojnic:** sdílený `ArrowHead` kreslí plný hrot v barvě zdroje s obrysem podle `--surface`, aby byl čitelný v obou tématech. `FineConnectionStroke` jej natáčí podle tečny křivky; SVG markery v `Graph` jej používají také pro vazby rozbalených stránek a ostatní styly. `markerUnits="userSpaceOnUse"` drží velikost hrotu nezávislou na tloušťce vybrané spojnice. Vazby rozbalených cílových stránek končí před kartičkou s rezervou pro šířku hrotu a obrys; zkrácení zachovává původní křivku i směr tečny. Tloušťka a počet vláken dál vyjadřují sílu vazby.
- **Přidání komponenty:** styl do souboru vrstvy, kam komponenta patří (`styles.css` demo a graf, `scan-workspace.css` skener); barvy přes tokeny, v `themes.css` pak jen přepis tokenů, ne duplikát pravidel.
- **Pravidlo:** žádné inline `<script>` ani externí CSS a fonty — blokuje je CSP z `public/_headers`. Inline `style=` atributy CSP povoluje.

## Rozšíření pro Chrome

`extension/` je historický lokální skener (Manifest V3), který dnes slouží jen starým mapám; aktuální skenování běží na serveru ([01](./01-backend.md)). Přesto je součástí každého buildu:

- `scripts/build-extension.mjs` (esbuild) sestaví `extension/background.ts` a `extension/runner.ts` do `build/extension` (produkce, minifikované, pouze originy `https://vizlinx.com` a `https://www.vizlinx.com`) a `build/extension-dev` (navíc `http://127.0.0.1:8797` a `http://localhost:8797`), vygeneruje `manifest.json` a zkopíruje `runner.html` / `runner.css`.
- Produkční složku zabalí do `dist/downloads/vizlinx-extension.zip`, na webu dostupné jako `/downloads/vizlinx-extension.zip`.
- Stabilní veřejný klíč a ID rozšíření jsou ve `shared/extension.ts`. `extension/extract.ts` (parser HTML) importuje i Worker (`worker/server-fetch.ts:8`) — změna extrakce mění chování serverového skeneru.
- Typy kontroluje `extension/tsconfig.json` (`@types/chrome`), chování testuje `npm run test:extension` ([05](./05-testing.md)). Instalace a ovládání: `extension/README.md`.
